x402-priceboard

The price list of x402 endpoints, without paying anything.

Every x402 server answers the first request with the price, the network and the payee. This asks a list of endpoints for those terms and prints a price board. Browsing the board does not pay anyone.

Usage

One endpointx402-priceboard https://api.venice.ai/api/v1/chat/completions
A listx402-priceboard --file endpoints.txt
Hosted boardnpm start, then open /. Set X402_PAY_TO before paid routes turn on.

How it works

  1. The probe sends one request and reads the payment-required header.
  2. The header is base64 JSON (or raw JSON), decoded and normalised into rows.
  3. The free board shows the cheapest row per catalog URL. It never attaches a payment signature.
  4. Paid routes answer 402 with PAYMENT-REQUIRED until a facilitator verifies and settles the buyer's signature into X402_PAY_TO.

Questions

Do I pay to look at the board?

No. The CLI, the HTML page and GET /api/prices only read public 402 terms. Payment starts when an agent calls /api/v1/probe or a seller calls /api/v1/featured.

Where does the money go?

Into the wallet in X402_PAY_TO. There is no built-in address. This server does not hold a private key; a facilitator you configure submits the buyer's signed transfer.

What do I set before the paid API will charge?

X402_PAY_TO and X402_FACILITATOR_URL. Until both are set, those routes return 503 and the free board keeps working. The public x402.org facilitator is for testnet only, so it will not settle Base mainnet USDC.

What is a featured listing?

A paid pin. The default is 1000000 atomic units ($1 of 6-decimal USDC) for 168 hours, then the row drops off the free board.
