x402-priceboard

The price list of x402 endpoints, without paying anything.

Every x402 server answers the first request with the price, the network and the payee. This asks a list of endpoints for those terms, normalises them and prints a price board. No wallet, no key, no payment.

View on GitHub npm README

What it does

Reads the 402 termsPrice, network, asset and payee.
Normalised networksBase, Ethereum and Solana in one column.
Cheapest firstThe board sorts by what a call actually costs.
Free endpoints tooA 200 means no payment is needed at all.

Usage

One endpointx402-priceboard https://api.venice.ai/api/v1/chat/completions
A listx402-priceboard --file endpoints.txt
For a READMEx402-priceboard --file endpoints.txt --markdown

How it works

  1. The probe sends one request and reads the payment-required header.
  2. The header is base64 JSON, decoded and normalised into rows.
